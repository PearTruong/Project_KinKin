# Tài liệu nguồn gốc

Các file `.docx` trong thư mục này được lưu bằng Git LFS để thành viên clone project có thể đọc trực tiếp. Nếu file chỉ hiện vài dòng bắt đầu bằng `version https://git-lfs.github.com/spec/v1`, chạy `git lfs pull` trong thư mục repo.

| File | Dùng khi |
|---|---|
| `Báo cáo 50K142.04.3007.docx` | Xem mục tiêu, quy trình, nghiệp vụ tổng thể |
| `đặc tả.docx` | Đọc Use Case, luồng chính/ngoại lệ, quyền và validation |
| `Đặc tả giao diện.docx` | Đọc mô tả từng màn, bảng trường và hình 53–155 |
| `anhxa.docx` | Đối chiếu ánh xạ yêu cầu và màn hình |
| `BPMN với UCD.docx` | Đối chiếu BPMN và Use Case Diagram |

Quy tắc ưu tiên vẫn theo `AGENTS.md`: báo cáo cho hành vi, Figma Final cho hình thức. Khi tài liệu mâu thuẫn với Figma hoặc API hiện tại, ghi rõ trong báo cáo task và nhờ Huy chốt trước khi sửa contract chung.
